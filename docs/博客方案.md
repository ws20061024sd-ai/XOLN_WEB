## 一、技术栈（实际使用）

| 层级 | 技术 | 状态 |
|------|------|------|
| 框架 | Next.js 16 `output: 'export'` | ✅ |
| 语言 | TypeScript | ✅ |
| 样式 | Tailwind CSS v4 | ✅ |
| 内容格式 | Markdown（.md） + gray-matter frontmatter | ✅ |
| 内容渲染 | 自写 MarkdownRenderer（支持图片/视频/B站/YouTube） | ✅ |

| 暗色模式 | CSS 变量 + data-theme + localStorage | ✅ |
| 搜索 | 客户端模糊搜索（自写，逐字匹配） | ✅ |
| 部署 | 腾讯云 COS 静态托管 + Lighthouse Docker API | ✅ |
| 版本管理 | Git + GitHub（ws20061024sd-ai/XOLN_WEB） | ✅ |
| 图片 | 本地 `public/images/` + 远程 URL | ✅ |
| 视频 | 本地 MP4 + Bilibili + YouTube 嵌入 | ✅ |

## 四、日常流程

两个阶段均已完成，日常只剩内容维护：

1. 写/改 `content/` 下的 `.md` 文件，本地 `localhost:3099` 预览
2. `git add/commit/push`（同时是备份）
3. `npm run build` → `node upload.js`（增量上传约 30-60 秒）
4. 腾讯云控制台刷新 CDN 缓存

> 详细操作见 [内容编辑指南](./内容编辑指南.md)；待办与扩展想法见 [当前状态与待办](./当前状态与待办.md)；运维检查见 [维护与注意事项](./维护与注意事项.md)。
